## List of Supported ML Kernels

CactusDB supports the following kernels/models:

- Matrix Multiply
- Matrix Addition
- Batch Normalization
- Cosine Similarity
- Decision Forest
- Decision Tree
- Dot Product
- Dropout
- Embedding
- String/Integer Encoder
- ReLU
- Softmax
- HuggingFace Serverless Endpoint
- HuggingFace Tokenizer
- Retrieval Augment Generation (RAG)
- Sequence Pooling
- SVD
- XGBoost
